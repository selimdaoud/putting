# Putting – simulateur de coup de putter

Simulation three.js (fichier unique `index.html`) d'un coup de putter au ralenti : balle avec alvéoles, profondeur de champ,
physique du choc (contact de Hertz, frottement), roulement sur le green selon le Stimp, swing automatique ou dessiné à la souris / au doigt,
courbe « Stroke Dynamics », niveau à bulle de plausibilité du geste.

Ouvrir `index.html` dans un navigateur (aucun serveur nécessaire). `three.min.js` est three.js r128.

Son d'impact : extraits de « putt.wav » par 170129 (Freesound #408260, licence CC0).
